# Desafio Prático — Auditoria e Caça aos Bugs

Projeto em Python + Pytest para testar e corrigir a função `calcular_desconto`.

## Requisitos

- Python 3.10+
- pytest

## Instalação

```bash
pip install -r requirements.txt
```

## Executar os testes

```bash
pytest -v
```

## Arquivos

- `desconto_original.py` — código recebido do Dev Jr.
- `desconto.py` — código corrigido.
- `test_desconto.py` — testes unitários automatizados.
- `CENARIOS.md` — cenários e bugs encontrados.
- `PRINT1_TESTE_FALHANDO.txt` — resultado dos testes contra o código original.
- `PRINT2_TESTE_PASSANDO.txt` — resultado dos testes após a correção.

## Resultado esperado

Após a correção:

```text
11 passed
```
